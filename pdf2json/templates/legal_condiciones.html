Qué es este servicio

Una herramienta web gratuita que convierte PDF a JSON. No hay registro, ni cuenta, ni pago. Al usarla aceptas estas condiciones.

Qué puedes subir

Solo ficheros sobre los que tengas derecho a hacerlo. No subas contenido ilícito, ni documentos con datos personales de terceros si no estás legitimado para tratarlos. Eres responsable de lo que subes.

Límites técnicos

Para que el servicio siga en pie para todos, cada petición tiene límites:

  • {{ limites.max_file_mb }} MB como máximo por fichero.
  • {{ limites.max_files }} ficheros como máximo por petición.
  • {{ limites.max_pages }} páginas como máximo por documento.
  • {{ limites.rate_limit }} por dirección IP.
  • {{ limites.timeout }} segundos como máximo de proceso por fichero.

No intentes sortear estos límites ni automatizar el servicio de forma que degrade su funcionamiento. Si lo haces, se puede bloquear el acceso desde tu dirección IP.

Qué no se garantiza

La conversión es automática. El modo estructurado deduce títulos y secciones a partir del tamaño de letra y de patrones de texto legal, y puede equivocarse. Los PDF escaneados sin capa de texto salen vacíos, porque la herramienta no hace reconocimiento óptico; cuando ocurre, el propio JSON lo indica con "ocr_required": true.

No se garantiza que el servicio esté siempre disponible ni que el resultado sea exacto o completo. No lo uses como única fuente para una decisión con consecuencias.

Tus ficheros

Los PDF se borran del servidor en cuanto termina la conversión, también cuando falla. No se conservan copias. Los detalles están en la política de privacidad.

Alojarlo tú mismo

El código es libre y público. Si necesitas garantías de disponibilidad o tratar documentos confidenciales, despliega tu propia instancia desde el repositorio.

Cambios

Estas condiciones pueden cambiar. La versión vigente es siempre la publicada en esta página, con su fecha de actualización.
